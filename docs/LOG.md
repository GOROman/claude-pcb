# 制作ログ

RP2350A 搭載 Pico 互換基板の設計記録。新しい作業を下に追記していく。

## 2026-11-10

### 01. 環境準備と方針決め

- 手元の Mac には KiCad が無く空き容量も少ないため、KiCad 10.0.6 が入っている mac-studio で生成・検証する。
  ローカルでスクリプトを書き、`tools/remote.sh` で rsync → mac-studio 上の KiCad 同梱 Python / `kicad-cli` を実行 → 結果を取り込む流れ。
- GUI を使わずに設計するため、回路図 (`.kicad_sch`) も基板 (`.kicad_pcb`) も Python から生成する。
  回路の定義（部品とネット）を 1 か所に置き、回路図と基板の両方をそこから作ることで食い違いを防ぐ。
- KiCad の S 式を読み書きする最小パーサ `tools/sexpr.py` を作成。ライブラリのシンボルからピン番号を取り出す
  `tools/dump_pins.py`、フットプリントのパッド寸法を見る `tools/dump_fp.py` も用意した。
- RP2350A のピン番号は KiCad 公式ライブラリ `MCU_RaspberryPi:RP2350A` で確認した。

### 02. 仕様の決定

- **USB コネクタ**: Type-C にしたい。ところが 16 ピン Type-C レセプタクルはシェル幅が約 8.94mm、シールド脚が中心から ±4.32mm にあり、
  Pico の上側取付穴（中心間 11.4mm、Ø2.1mm、内側の縁が中心から 4.65mm）と重なる。KiCad ライブラリの Type-C レセプタクルを全部調べたが両立するものは無かった。
  → オーナー判断で「USB-C を載せ、上側 2 穴は省略」に決定。
- **3.3V 電源**: 純正 Pico の RT6150B と同じ昇降圧構成にするため TPS63001 (3.3V 固定、入力 1.8〜5.5V) を採用。
  EN と PS/SYNC ピンの極性が Pico の `3V3_EN` / GPIO23 の使い方と同じなので、そのまま互換にできる。
- **基板**: 4 層。部品は表面のみ（Pico と同じく、端面スルーホールでモジュールとして実装できるよう裏面は平らにする）。
- **Flash**: 2×3mm の USON-8 (W25Q32RV など)。

### 03. 回路定義と回路図の生成

- `tools/design.py` に全部品とネットを定義（53 部品）。回路図と基板の両方がこのファイルを読む。
- `tools/gen_sch.py` が KiCad ライブラリからシンボルを取り出して回路図を生成する。派生シンボル（`extends`）は親を複製して平坦化。
  接続は各ピンから短い配線を出してネットラベル／電源シンボルで表現した。
- 回路の要点:
  - USB Type-C: CC1/CC2 に 5.1kΩ、D+/D- に 27Ω 直列。
  - VBUS → ショットキー (MBR120VLSFT1G) → VSYS → TPS63001 → +3V3。`3V3_EN` は VSYS へ 100kΩ プルアップ、PS/SYNC は GPIO23。
  - RP2350 内蔵 SMPS: VREG_LX → 3.3µH → +1V1 (DVDD)、VREG_AVDD は 33Ω + 4.7µF のフィルタ。
  - GPIO24 = VBUS 検出 (5.6k/10k)、GPIO29 = VSYS/3 (200k/100k、3V3 がゲートの N-FET で遮断)、GPIO25 = LED。
  - ADC_AVDD は Pico と同じく ADC_VREF (3V3 から 200Ω + 2.2µF) に接続し、35 番ピンにも出す。
  - 40 ピンは `Conn_02x20_Counter_Clockwise` 1 個で表現（ピン番号がそのまま Pico のピン番号）。
- `kicad-cli sch erc` の結果: 電気的なエラー・警告は 0 件。
  残っているのは「シンボル／フットプリントライブラリが設定に無い」という警告のみで、mac-studio の CLI 環境にグローバルライブラリ表が無いことが原因（回路の問題ではない）。
